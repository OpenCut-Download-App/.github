## 👁️ At a Glance
OpenCut for Windows is a free video editor and clip cutter that runs entirely on your PC. It is built for anyone who needs to grab raw footage, cut it down, and export a clean result without paying for a subscription. Since open cut editing is handled locally, your media stays on your machine, and because the OpenCut app is open-source on GitHub, you can see exactly how it works. It is a practical choice for short clips, social posts, and quick projects on everyday Windows hardware.

## ❓ FAQ
**Is OpenCut free?**
Yes. OpenCut is a free, open-source video editor for Windows, and its code is openly available on GitHub.

**Which versions of Windows are supported?**
OpenCut runs on modern 64-bit Windows, including Windows 10 and Windows 11. The latest stable release is recommended.

**Is my data secure?**
Your editing happens locally on your PC, so you stay in control of your files instead of handing them to a remote server.
